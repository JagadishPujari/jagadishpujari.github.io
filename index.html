About

Twelve years, one throughline

I've spent my career moving between hands-on engineering and system design — full-stack development, then platform architecture, and for the last few years, Generative AI architecture for enterprise clients.

Recent work has centered on production GenAI systems: RAG pipelines from ingestion through reranking, multi-LLM orchestration across Azure OpenAI, Claude, and Gemini, and agentic workflows built with LangChain and LangGraph — including work for Vodafone Idea. Selected work

Systems I've built

A few projects from recent platform and AI architecture work, chosen for the range of problems rather than polish.

AI Mentor Bot — voice-driven teaching agent

A prototype built to sit inside live Microsoft Teams classes as a guest participant and mentor learners in real time. Rather than building Teams bot infrastructure from scratch, I integrated via Recall.ai's guest-bot and Output Media API, then designed a Pipecat-style voice pipeline: Deepgram for speech-to-text, an LLM for reasoning, ElevenLabs/Cartesia for speech-out. Debugged real production issues along the way — missing TTS voices in a headless browser, echo filtering, buffered audio playback, and swapping LLM providers after hitting rate limits mid-class.

Recall.ai · Deepgram · Claude · ElevenLabs · Node.js · WebSockets

Audit & Activity Intelligence Dashboard

Built after a production incident where a session reschedule didn't sync downstream to a partner assessment platform. The dashboard gives admins a platform-hygiene view, an activity feed with before/after diffs, and a proactive readiness board — combining live database state with CloudWatch logs joined on a shared correlation key, behind a read-only backend proxy so AWS credentials never reach the client.

Spring Boot 4 · WebFlux · React 19 · TypeScript · Vite

Learner portal redesign at platform scale

Led the presentation-layer redesign of a large banking client's learner portal onto a new design system — on a live, legacy React/Redux codebase that couldn't afford instability. Scoped the work to presentation only, chose CSS Modules and design tokens over a framework swap, and piloted the new look on the homepage hero before rolling it out further.

React 18 · Redux · Redux-Saga · CSS Modules · Design tokens

Programmatic demo video pipeline

A ~75-second, 16-scene platform demo built with Remotion — React components rendered to video rather than hand-edited. Later extended into a narrated version: a script goes in as JSON, gets converted to speech, timing is extracted from the audio, and animation cues sync automatically to the narration.

Remotion · TTS pipeline · Script-to-video automation
